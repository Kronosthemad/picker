# picker
This is just a simple ranger like file manager written in C#. It is still in early development, so expect bugs and missing features.
As of now, it only supports basic directory navigation and file opening. I plan to add more features like file operations (copy, move, delete), search functionality, and customizable keybindings in the future.
it does have icons and colors though, so it should be visually appealing. If you want to contribute or have any suggestions, feel free to open an issue or submit a pull request.
